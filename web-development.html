Chapter 1: Introduction to Web Development

Web development is the process of creating websites and web applications that users access through browsers.

What is a Website?

A website is a collection of web pages connected together and hosted on a web server.

Main Technologies

  • HTML — structure and content
  • CSS — design and presentation
  • JavaScript — behavior and interactivity
  • Backend — server-side processing
  • Database — storing information
Remember: HTML structures the page, CSS styles it, and JavaScript makes it interactive.

Frontend vs Backend

Frontend development deals with what users see and interact with. Backend development handles server logic, databases, authentication and APIs.

Chapter 2: How the Web Works

When you open a website, your browser communicates with a server through the Internet.

Basic Process

  1. You enter a website address.
  2. The browser sends a request.
  3. The server receives the request.
  4. The server sends a response.
  5. The browser displays the page.
Example:
Browser → Internet → Web Server → Response → Browser

HTTP and HTTPS

HTTP is a protocol used for transferring web information. HTTPS is the secure version that uses encryption.

GET /index.html HTTP/1.1 Host: example.com

Chapter 3: HTML Basics

HTML stands for HyperText Markup Language. It is the standard language used to structure web pages.

Basic HTML Structure

<!DOCTYPE html> <html> <head> <title>My Website</title> </head> <body> <h1>Hello World</h1> <p>Welcome to my website.</p> </body> </html>

Common HTML Elements

  • <h1> — heading
  • <p> — paragraph
  • <a> — link
  • <img> — image
  • <ul> — unordered list
  • <ol> — ordered list
  • <div> — container
HTML elements normally have an opening tag and a closing tag, although some elements such as images do not require closing tags.

Chapter 4: HTML Elements and Forms

HTML forms allow users to enter and submit information.

Common Form Elements

  • input
  • label
  • textarea
  • select
  • button
<form> <label>Full Name</label> <input type="text" name="name" placeholder="Enter your name" > <label>Email</label> <input type="email" name="email" > <button type="submit"> Submit </button> </form>

Input Types

  • text
  • email
  • password
  • number
  • date
  • file
  • checkbox
  • radio

Chapter 5: HTML Links and Images

Links allow users to navigate from one page to another. Images add visual content to a web page.

Creating a Link

<a href="https://example.com"> Visit Website </a>

Adding an Image

<img src="photo.jpg" alt="My Photo" width="300" >

Important Attributes

  • href — destination of a link
  • src — image location
  • alt — alternative image text
  • target — controls where a link opens

Chapter 6: CSS Basics

CSS stands for Cascading Style Sheets. It controls the appearance and layout of HTML elements.

Example

Three Ways to Add CSS

  1. Inline CSS
  2. Internal CSS
  3. External CSS

Common CSS Properties

  • color
  • background
  • font-size
  • margin
  • padding

Chapter 7: CSS Layout

CSS provides several techniques for arranging elements on a web page.

Flexbox

.container { display: flex; justify-content: center; align-items: center; gap: 20px; }

Grid

.container { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }

Responsive Design

Responsive design makes websites adapt to different screen sizes such as phones, tablets and computers.

@media (max-width: 768px) { .container { grid-template-columns: 1fr; } }
A professional website should work correctly on both mobile devices and desktop computers.

Variables

Chapter 9: JavaScript Events

Events happen when users interact with a web page.

Common Events

  • click
  • submit
  • change
  • input
  • mouseover
  • keydown
document .getElementById("myButton") .addEventListener("click", function(){ alert("Button clicked!"); });

DOM

DOM stands for Document Object Model. It allows JavaScript to access and modify HTML elements.

Chapter 10: Working with Forms

JavaScript can validate form data before it is submitted.

const form = document.getElementById("form"); form.addEventListener("submit", function(event){ event.preventDefault(); const email = document.getElementById("email").value; if(email === ""){ alert("Email is required!"); }else{ alert("Form submitted!"); } } );

Why Validation Matters

  • Improves user experience
  • Prevents incomplete information
  • Reduces invalid submissions
  • Provides immediate feedback

Chapter 11: Introduction to Firebase

Firebase is a platform from Google that provides services for modern web and mobile applications.

Firebase Services

  • Authentication
  • Cloud Firestore
  • Storage
  • Hosting
  • Cloud Functions

Authentication

Firebase Authentication can be used for registration, login, password reset and user management.

Firestore

Cloud Firestore is a NoSQL database used to store application data in collections and documents.

users | ├── userId │ ├── name │ ├── email │ └── createdAt
In BH Skills Hub, Firebase is used for authentication, student progress and certificate records.

Chapter 12: Building a Complete Web Project

A complete web project combines HTML, CSS, JavaScript, authentication, database services and good user experience.

Project Development Process

  1. Define the problem
  2. Plan the features
  3. Create the HTML structure
  4. Design using CSS
  5. Add JavaScript functionality
  6. Connect backend services
  7. Test the project
  8. Make it responsive
  9. Deploy the project

Example Project Structure

my-project/ │ ├── index.html ├── login.html ├── signup.html ├── dashboard.html ├── style.css ├── script.js │ └── assets/ ├── images/ └── icons/
